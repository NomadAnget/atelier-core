# Atelier 宪法(纲领)

> 本目录是 Atelier 体系的**宪法**:架构 / 契约 / 纪律以它为准。各仓 README 只给本地导引。
> 本篇是纲领(铁律 + 认知隔离 + 同步律);机制细节见同目录分篇。

Atelier 只做一件事的地基:**模块间通信的中转站 + 存储枢纽 + 装配注册表**。
一切设计服务于一个目标——**认知隔离**:新增/修改一个域时,需要理解的上下文半径 =
**本域 `header.py` + 本 docs**,不必读其他域的实现。

## 铁律(registry / 测试机器校验,违反即抛错)

1. **单一逻辑**:同一逻辑不散落多处。加新实现前先搜现有的。
2. **发布权随目录走**:topic 首段必须等于域名,只有拥有域能发布;**写权随目录走**:
   表名前缀=域名,越域写被拒;读全局开放(`hub.read`)。
3. **头文件是唯一窗口**:`DOMAIN` / `PUBLISHES`(topic→schema) / `SUBSCRIBES`(pattern→槽位)
   三件套;未声明的发布、载荷类型不符、槽位缺失/多余,一律立即抛错。头文件零实现。
4. **认知隔离 + 域内纪律**:代码只放对的域;跨域走消息,不直调他域实现。域间 import 由
   `test_import_discipline` (AST 扫描)机器封禁——规则变更**先改测试白名单再改代码**。
5. **引擎按设备分级,一律不常驻**:引擎域是全系统的计算中心,任何域可调,但分两级——
   在本进程把权重载上 **GPU** 的重引擎(`HEAVY_INFERENCE=True`)只准在 `pipelines/` 上下文调用
   (域里随手起模型会和运行中的任务抢显卡);**纯 CPU 推理或只调外部服务**的轻引擎任何域可调
   (不得跑在事件循环)。**任何引擎(含模块级函数持有的模型)用完即释放,不得常驻**:模型只活在
   一次调用 / 一个 `with` 作用域内。分级判据是**设备**,不是"import 了哪个推理框架"。
   细则与执法见 [domains.md](domains.md)「引擎分级与不常驻」。
6. **显式失败,不静默兜底**:前置条件缺失就抛清晰错误,不走隐形回退路径。
7. **Linux only**:不做跨平台兼容改动。
8. **宪法同步律**:契约/规则/纪律的变更,**先改本 docs 对应篇再写代码**——
   docs + 本域 header 是其他域作者的**全部上下文**,docs 落后一步,认知隔离就塌一角。

## 认知隔离

- 改一个域 = 只碰它的 header/schema/impl + 它在 docs 里的段落。跨域协作走消息,不直接调别域实现。
- 域向系统只露三张声明面:`header.py`(总线契约)、`schema.py`(存储)、`build.py`(装配声明,
  可选)。**组装是基础设施的职责**,域只声明"我是什么类型、我怎么构造",绝不接管组装机制
  (`bus.mount` / 网关 / 子进程生死全归基础设施)。

## 三层结构(内核 / 域 / 变体)

| 层 | 是什么 | 仓 |
|---|---|---|
| **内核** | 总线 + 存储枢纽 + 装配注册表 + 组装原语,零业务 | `atelier-core`(uv 依赖) |
| **域** | 消息总线上的自治单元(web/scheduler/task/engines/…) | `atelier-<域>`(git 子模块,挂 `src/<域>`) |
| **管线** | 任务域的可组合插件(video/digest) | `atelier-pipeline-<名>`(子模块,挂 `src/pipelines/<名>`) |
| **变体** | 组装某几个域+管线+前端 = 一个产品 | `atelier-<品类>`(reel-solo / reel-creator / studio) |

内核对"域住哪"一无所知:发现/装配全按 `domain_root` 参数走(变体传自己的包)。详见
[architecture.md](architecture.md)。

## 显式失败

- 配置:未知节/键、类型不符 → 启动即抛错;文件缺失合法(全默认,来源入日志)。
- 契约:声明的图上不允许悬空边(发布无订阅 / 订阅无发布 / 槽位漏接)——组装期红灯。
- 存储:实表结构漂移 → 挂载即抛错,绝不自动改表(报警自动化,动刀人工化)。
- 投递:"发出去 = 一定会被处理到,或显式进死信",没有无声蒸发。
